# Moodboard

Moodboard purpose: exploration and inspiration.

Build one coherent visual world with approximately 6–9 reference directions:
1. Hero world
2. People / lifestyle
3. Product / object
4. Color atmosphere
5. Material / texture
6. Graphic language
7. Cultural detail
8. Editorial composition
9. Optional motion frame

First create one MASTER VISUAL PROMPT containing:
brand name, category, personality, visual tension, Creative North Star, color behavior, lighting, composition, materials, texture, cultural context, realism and abstraction.

Then derive individual image prompts from that same system.

If image generation is available and requested, generate visuals. Otherwise provide production-ready prompts and clearly state that images were not generated.
