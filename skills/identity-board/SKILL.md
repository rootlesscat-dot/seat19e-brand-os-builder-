# Brand Identity Board

Identity Board purpose: decision and execution.

Include:
- Brand Name
- Brand Essence
- Tagline
- Personality
- Color Direction
- Typography Direction
- Hero Image Style
- Lifestyle Image Style
- Product / Object Style
- Graphic Elements
- Composition Principle
- Tone of Voice
- Application Examples
- Do / Don't

Recommended layout:
TOP: Brand Name / Tagline / Brand Essence
LEFT: Hero / Lifestyle / Product images
RIGHT: Palette / Type / Graphic Elements / Copy
BOTTOM: Principles / Applications / Do & Don't

The board must be a practical design reference, not a decorative collage.
