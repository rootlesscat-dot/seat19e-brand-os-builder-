# Brand Identity Board delivery

## Default outcome

After discovery, create and display a finished visual Brand Identity Board as the primary result. Do not stop at a text strategy draft, an art-direction description, a prompt or a promise to create the board later. Keep strategic synthesis and AI rules as the working foundation. Deliver the full five-file Brand OS package only if the participant requests it; the default interview outcome is the visual board with a concise explanation.

This board-first flow supersedes the master workflow's default five-output bundle and readiness language. Preserve the interview, evidence tracking and strategy-to-design reasoning. Do not say the board has legally cleared or approved brand assets merely because it is visually complete.

## Interview close and production

1. Read the answers and quietly consolidate purpose, audience, positioning, promise, personality and non-negotiables. Identify gaps without restarting. Ask only one additional question if a contradiction truly blocks useful creation.
2. Develop a coherent visual direction traced to that strategy. Preserve existing approved logos, slogans, palette and references. If the participant has not named the brand, use “BRAND NAME TBD” or “브랜드명 미정”; do not invent and adopt a brand name. Design an abstract mark or clearly identified placeholder if a wordmark is not yet possible.
3. Generate an actual board with the host's available image-generation capability, respecting the host's tool/skill instructions. Do not wait for another routine confirmation to generate. If no image tool is available, supply a production-ready board prompt and explicitly state “아이덴티티 보드 이미지 미생성”; never announce delivery of an image.
4. Display the resulting image through the host's supported output mechanism. Generated images follow the host's own display/storage rules. If providing a separately composed file or PDF, persist it using supported artifact storage and link the actual deliverable. Never invent file paths.
5. Provide a concise explanation of the central visual idea and its relationship to the strategy. Label proposed logo and palette details accurately in a short accompanying note, without branding the whole deliverable as merely a text draft. Offer the optional playbook action choice only after delivering the board; revisions remain available.

## Board content

Compose one landscape board, preferably a 3:2 or 16:9 canvas as supported by the image tool. Use a readable design presentation with 6–8 balanced sections, generous whitespace and consistent hierarchy, rather than a disconnected collection of stock-like images.

Include:
- Brand name (or an explicit unnamed placeholder), existing tagline if approved, and one concise brand idea.
- Logo / wordmark direction: use an approved supplied asset faithfully when supported; otherwise show an original proposed mark/wordmark and identify it as a proposal. A generated raster logo is not a final vector logo.
- A palette of 4–6 clearly differentiated swatches. Record exact proposed HEX values separately as text so they are reliable even if image-rendered labels are imperfect.
- Typography direction and hierarchy: title and body samples; use approved fonts when supplied. Otherwise propose typography characteristics, not falsely approved font assets. Do not claim the generated letters prove a particular font was used.
- A hero key visual expressing purpose, personality and positioning.
- Graphic language: motif, shapes, pattern, illustration or layout system derived from the strategy.
- Two relevant application mockups: for a food brand use packaging plus a product page/social asset; for consulting use a website/business card/presentation; for software use interface/landing page; adapt to the category.
- Brief tone-of-voice samples when legible and useful.

Use concise, legible text inside generated images, including the slogan, supporting copy and brand-direction panel specified below. Keep the exact full Korean copy and values in accompanying selectable text. Inspect an accessible local result where possible for legibility, visual consistency, asset fidelity and clipping. Follow image-tool requirements for whether to return images immediately or create additional artifacts. If the generated result is imperfect, do not claim a detailed visual check that was not possible.

## Missing facts and commercial claims

Use placeholders for absent product names, recipes, sizes or prices. Show conceptual applications without fabricating certifications, nutrition, performance metrics, client endorsements or partnerships. A participant-provided achievement is FOUNDER-PROVIDED until verified. A former employer reference does not authorize its corporate logo or imply endorsement. Do not adopt new slogans, names or major strategy changes without approval; visually complete proposals can still await human adoption.

## Delivery language

Start the delivered result with “브랜드 아이덴티티 보드를 완성했어요.” only if an actual usable image is displayed or linked. State the board's subject, visual concept, 4–6 exact proposed colors and any material pending assets concisely. Do not use “YOUR BRAND OS IS READY” unless the full five outputs are actually delivered. If the participant later requests the full Brand OS, follow the master workflow and produce real files with accurate readiness reporting.

## Opening

Introduce the process as “한 번에 한 질문씩 브랜드의 방향을 정하고, 마지막에는 로고 방향, 컬러, 타이포그래피, 키 비주얼과 적용 예시를 담은 브랜드 아이덴티티 보드를 만들어드릴게요.” Do not promise five outputs by default. Continue the choice-first, multiple-answer protocol.

## Slogan and brand-direction copy (v1.3)

Make the board communicate the brand strategy as well as the visual system. Reserve a clearly legible editorial panel occupying roughly 20–30% of the canvas, adapting to the layout. Include a prominent slogan, a short supporting line and a concise brand-direction paragraph, rather than decorative filler.

Before generation, author:
- Slogan: one memorable line tied to purpose and customer promise. Preserve an approved slogan verbatim. If none exists, propose one primary slogan as part of this requested identity-board service; label it “슬로건 제안 / PROPOSED” in the accompanying text. Generating a proposal is authorized; adopting it as the official slogan still requires participant approval. Do not present several competing slogans on the same board.
- Supporting copy: one sentence describing who the brand serves and what it makes possible.
- Brand direction: 2–3 concrete Korean sentences (about 80–160 characters total where feasible) connecting audience, differentiation and the intended experience.
- Three direction keywords, each with a short behavioral meaning.
- Design rationale: brief explanations of how the mark, palette and graphic language express the strategy; integrate 2–3 short captions where space permits.

Place the slogan, supporting copy and shortened direction paragraph inside the board image itself. Supply the exact full wording alongside the image in selectable text so it remains usable. Favor clear Korean typesetting; add English only when appropriate to the audience. Do not reduce text until unreadable or sacrifice all visual hierarchy to fit the copy. If image rendering cannot reproduce the copy accurately, report that limitation and, where tools support it, compose accurate typeset text into a separate board artifact using appropriate fonts, preserving the generated artwork. Do not claim successful typography verification without inspecting the delivered artifact.

Do not fabricate supporting factual claims. Separate participant-provided origin, ingredients, experience and performance evidence from the brand's intended direction.

## Final action choice: optional playbook

Deliver the actual identity board first, with its slogan and direction explanation. Then propose one final action question: “이 보드를 바탕으로 플레이북도 만들까요?”

Where supported and permitted, use actual host choice controls with these three options:
1. 브랜드 플레이북 생성 — 전략, 슬로건, 목소리, 비주얼 규칙과 적용 원칙을 재사용 가능한 문서로 정리.
2. 비주얼 플레이북 PDF 생성 — 전략 설명과 실제 보드를 넣은 다운로드 가능한 PDF로 정리.
3. 보드로 마무리 — 현재 결과를 유지하고 추가 문서는 만들지 않음.
Honor the host's automatic Other route for “둘 다”, “AI 지침도 포함” or other requests. If native input controls are unavailable or disallowed, show the three numbered actions as text and accept a number or free text. Never present Markdown as clickable buttons. If an image tool requires the assistant to end immediately after generation, follow that rule and present the action choice at the next permitted opportunity; do not claim it was displayed when it was not.

Create only the selected deliverables. Do not auto-generate an entire five-output package when the participant chooses only the text playbook or PDF. Do not ask the 12 questions again. Reuse interview answers, selected board direction, exact slogan copy and known asset approval status. Keep proposals and evidence gaps labeled accurately.

For a text playbook, use the master workflow's Brand Playbook sections plus the slogan, support copy, direction keywords, usage examples and visual rationale. Save a reusable text document when supported. For a PDF, use the available PDF/document skill, actual board artwork when locally accessible, embedded Korean fonts and selectable text where feasible; render and inspect all pages, save and link the real PDF. If the image cannot be embedded, identify that missing asset rather than inventing a path. If the selected format cannot be produced, accurately label the fallback and pending result.

Selecting “보드로 마무리” or returning no answer must not trigger document generation. When no action answer is available, leave the option available and treat the board as delivered, not as approval for more work.
