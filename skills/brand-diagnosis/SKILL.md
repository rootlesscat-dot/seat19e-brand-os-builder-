# Brand Diagnosis

Evaluate:
- Distinctiveness
- Relevance
- Credibility
- Emotional Value
- Cultural Potential
- Consistency
- Execution Potential

For each dimension provide:
- diagnosis
- evidence from the Brand OS
- risk
- one improvement

Optional lenses when requested:
- smallest viable audience / remarkable value / permission / tribe / tension
- mystery / sensuality / intimacy
- identity, salience, differentiation and coherence principles

Use published conceptual frameworks as analytical lenses. End with the three highest-priority strategic moves.
