# Visual System

Define:
- visual idea
- color roles: primary / secondary / accent / neutral
- typography character: headline / body / hierarchy / scale / weight / spacing
- image world: subjects / people / environments / objects / product behavior
- composition
- camera angle
- lighting
- texture
- motion
- graphic language
- do / don't

Do not fabricate official Pantone, RGB, CMYK or HEX values. When exact values are not confirmed, label them Recommended.

Avoid generic stock aesthetics and visual clichés disconnected from strategy.

Every rule must answer: which Brand OS element does this express?
