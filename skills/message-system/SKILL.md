# Message System

Create:
- Master Brand Message
- Audience Tension Message
- Functional Value Message
- Emotional Value Message
- Reason-to-Believe / Proof Message
- Creative / Campaign Message
- Headline examples
- Short-form social copy
- CTA behavior
- Words to use / avoid

Keep strategic claims traceable to evidence. Do not turn hypotheses into facts.

The message hierarchy should help multiple teams write consistently without forcing identical wording everywhere.
