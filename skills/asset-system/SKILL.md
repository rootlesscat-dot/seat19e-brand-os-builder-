# Asset System

Translate the Brand OS into execution.

Create:
- Asset System / Asset Overview
- category-specific asset modules
- Asset Pairing Guide
- channel / format guide
- launch / always-on / campaign / retail / social / sales grouping when relevant
- Must Have / Should Have / Nice to Have output inventory

Pairing Guide must explain:
WHAT can be paired
WHY it works
WHERE to use it
WHEN to use it

Examples:
Hero Image + Short Headline
Product Shot + Functional Proof
Lifestyle Image + Emotional Message
Founder / Expert Image + Expertise Story
UGC + Social Proof
Illustration + Education Content

Adapt the taxonomy:
F&B/product, service/consulting, software, fashion/beauty and other sectors should not receive identical asset lists.
