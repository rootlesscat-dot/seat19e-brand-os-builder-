# Choice-first interview reference

Use these banks as adaptable examples, not an exhaustive taxonomy or validated brand answers. Offer approximately 8–12 useful candidate directions across the question's full bank where appropriate. Avoid maximizing count at the expense of relevance. Always accept "기타: 직접 입력", a combination, or the participant's own wording.

## Host controls

Inspect the actual input-tool capability at runtime. Use a native question control only when available and allowed for this task. Send exactly one question. With a three-option cap, group the bank into three comprehensible category families, then show a contextual detail question next turn. Use descriptive group names, not "1–4". Preserve the Q number across sub-steps. A built-in free-text Other can accept a unique answer or several numbered choices. If only text is supported, show a concise numbered list and invite numbers or a custom answer. Never render fake buttons or claim that Markdown is interactive.

For unique names and evidence, prefer a short free-text question. Never replace a participant's specific story with a prewritten generic option. Do not repeatedly ask for response-mode selection. If there is no response, do not invent one or immediately repeat the same control.

## Question banks

### Q1 — 브랜드 유형

후보: 전문 서비스·컨설팅 / 식품·음료 / 패션·뷰티 / 생활·리빙 / 테크·SaaS·플랫폼 / 교육·코칭 / 건강·웰니스 / 공간·여행·경험 / 문화·콘텐츠·엔터테인먼트 / 개인 브랜드·커뮤니티

기타: 직접 입력. 조합하거나 다른 표현을 써도 된다.

선택 후 브랜드명과 주요 제품·서비스 중 아직 모르는 항목을 한 번에 하나씩 직접 입력으로 수집한다.

### Q2 — 존재 이유

후보: 복잡한 일을 쉽게 만들기 / 더 많은 사람에게 기회 열기 / 일상의 즐거움 높이기 / 사람과 문화 연결하기 / 건강한 삶 돕기 / 낭비와 환경 부담 줄이기 / 새로운 표현과 창작 돕기 / 고객의 성장과 도약 돕기 / 소외된 니즈 해결하기 / 더 공정하고 신뢰할 수 있는 시장 만들기

기타: 직접 입력. 조합하거나 다른 표현을 써도 된다.

업종과 고객에 맞는 구체적 변화로 바꿔 제시한다. 추상적인 선택만으로 purpose를 확정하지 않는다.

### Q3 — 5년 후 역할

후보: 고객이 가장 먼저 찾는 전문가 / 새로운 기준을 만드는 브랜드 / 특정 커뮤니티의 중심 / 일상에서 없어서는 안 될 동반자 / 지역과 세계를 연결하는 다리 / 도전을 가능하게 하는 파트너 / 문화를 이끄는 창작자 / 믿을 수 있는 대안 / 다음 세대를 키우는 브랜드 / 작지만 영향력 있는 전문 브랜드

기타: 직접 입력. 조합하거나 다른 표현을 써도 된다.

규모·매출만으로 비전을 정의하지 않는다.

### Q4 — 우선 고객

후보: 일반 소비자 / 특정 취향·라이프스타일 고객 / 가족·보호자 / 학생·학습자 / 창업자·스타트업 / 중소기업 경영자 / 대기업 실무팀 / 기업 리더·의사결정자 / 크리에이터·전문가 / 공공·비영리 조직 / 특정 지역·해외 고객

기타: 직접 입력. 조합하거나 다른 표현을 써도 된다.

앞선 업종을 기준으로 맞지 않는 항목을 제외하고 가장 먼저 함께할 집단 하나를 좁힌다.

### Q5 — 고객의 문제

후보: 선택지가 많지만 판단 기준 부족 / 비용 부담 / 시간·과정의 비효율 / 품질·결과의 불확실성 / 자기 취향에 맞는 대안 부족 / 접근성·기회 부족 / 문화·언어의 장벽 / 전략과 실행의 단절 / 기술 변화에 적응하기 어려움 / 신뢰할 정보 부족 / 소속감·연결 부족

기타: 직접 입력. 조합하거나 다른 표현을 써도 된다.

선택은 고객 조사 결과가 아니다. NEEDS CUSTOMER VALIDATION으로 기록한다.

### Q6 — 선택할 이유

후보: 깊은 분야 전문성 / 독특한 문화 이해 / 전략부터 실행까지 연결 / 개인화된 서비스 / 빠르고 유연한 실행 / 차별화된 기술·방법론 / 검증 가능한 결과 / 전문 네트워크·접근성 / 접근 가능한 가격·서비스 / 창업자의 독특한 관점 / 일관된 품질·경험

기타: 직접 입력. 조합하거나 다른 표현을 써도 된다.

선택한 강점은 주장으로 기록한다. 증거가 없으면 UNVERIFIED이며 경쟁사 우위를 검증한 것으로 쓰지 않는다.

### Q7 — 고객에게 줄 가치

후보: 판단의 명확성 / 시간과 노력 절감 / 새로운 성장 기회 / 자신감과 주도권 / 더 나은 결과물 / 특별한 즐거움·경험 / 연결과 소속감 / 건강·삶의 질 개선 / 더 쉬운 접근 / 일관된 브랜드 경험

기타: 직접 입력. 조합하거나 다른 표현을 써도 된다.

하나의 핵심 가치를 우선하고 기존 슬로건은 보존한다. 결과를 보장하는 표현은 제안 상태로 둔다.

### Q8 — 성격 3가지

후보: 호기심 많은 / 대담한 / 따뜻한 / 명료한 / 실용적인 / 장난기 있는 / 섬세한 / 독립적인 / 문화에 열린 / 차분한 / 실험적인 / 신뢰할 수 있는

기타: 직접 입력. 조합하거나 다른 표현을 써도 된다.

3개를 수집한다. 각 성격의 행동과 과해졌을 때 피할 점은 DRAFT로 해석한다.

### Q9 — 목소리와 비주얼

후보: 간결하고 정돈된 / 대담하고 대비가 강한 / 따뜻하고 사람 중심인 / 잡지 같은 에디토리얼 / 위트 있고 경쾌한 / 차분하고 절제된 고급감 / 문화적 맥락이 풍부한 / 실험적이고 예상 밖인 / 자연스럽고 유기적인 / 정밀하고 기술적인 / 생생하고 감각적인 / 익숙하고 일상적인

### Q10 — 타협하지 않을 원칙 3가지

## Example opening with a three-option host

Q1 첫 단계: "만들고 싶은 브랜드는 어떤 분야에 가까운가요?"
- 제품·소비재: 식품, 뷰티, 패션, 리빙 등
- 서비스·기술: 컨설팅, 교육, 공간, 건강 서비스, 앱·플랫폼 등
- 개인·문화·커뮤니티: 개인 브랜드, 콘텐츠, 창작, 커뮤니티 등
- Use the host's automatic Other/free-text route; do not add a fourth explicit option if the schema forbids it.

After "서비스·기술", adapt the next Q1 sub-step to professional services, education/experience or technology/platform, with Other still available. If the participant supplies "SEAT19E, 글로벌 브랜드 전략과 크리에이티브 실행 컨설팅" directly, record those details and ask only the next missing detail or Q2.

## Answer handling

A selected option confirms the participant's stated preference only. Keep custom wording verbatim in the interview record. Label strategic synthesis DRAFT / PROPOSED until approved. Customer insights require customer validation; performance claims require evidence. Choosing "기타" without any text leaves the question unanswered. Support corrections without restarting discovery.


## Multiple-answer protocol (v1.1.1)

Support both routes without repeatedly asking participants to pick an input mode:

1. Numbered reply: For questions where combinations are meaningful, label “복수 응답 가능” and assign stable visible numbers. Invite “기타 입력에 번호 여러 개를 적어주세요. 예: 1, 3, 5. 직접 설명을 덧붙여도 좋아요.” When the native control allows only three options, never pretend it displays more. For a broad 8–12 item bank, show the numbered text list outside the control, and use the permitted Other/free-text route (or an ordinary chat reply) to submit multiple numbers. The list is text, not additional buttons. Keep the active list available in the same turn. If only three choices are visible, use a valid example such as “1, 3”, not “1, 3, 5”.
2. Accumulating reply: Accept one choice at a time. Keep “현재 선택: …” in the next turn, exclude already selected items, and ask only the next selection under the same question number. For top-three questions, collect until three valid distinct items are supplied, then move on. For open-ended combinations, accept “완료” through free text to stop; do not invent an extra button beyond the schema limit. If the participant requests this route explicitly, honor it.

Parse comma-separated, space-separated and Korean-separated numbers such as “1, 3, 5”, “1 3 5” and “1번과 3번”. Resolve numbers only against the active visible list; never use hidden bank positions. Deduplicate repeated choices while preserving order. Record custom text alongside selections, including mixed replies such as “1, 3 + 기타: 가족과 함께 즐기는 맛”. Do not treat custom input as replacing the selected numbered items.

Keep numbering stable within the active list. When a new subset is shown, retain its original IDs or clearly present a new active list; never silently reinterpret a previous ID. Maintain selected labels, IDs and custom text in conversation state. Support “3번 취소”, “1번 대신 4번”, “전부 초기화” and “완료”. An out-of-range number requires one focused clarification and must not be guessed.

For Q8/Q10/Q12, request three priorities. If more than three are provided, preserve all as candidates and ask one question to identify the top three; if fewer, accumulate the remainder. Honor a participant's request to continue with fewer and mark the gap. For Q2/Q3/Q4/Q6/Q7, accept multiple candidates but ask for one priority only when the ambiguity blocks useful strategy; distinguish a primary direction from secondary ones instead of merging everything into a generic claim. A single-answer question remains single-answer unless the participant proposes a combination.
